============================================================
 HOW TO WRITE YOUR NEXT WRITEUP (MARKDOWN WORKFLOW)
============================================================

You no longer need to hand-write HTML for each writeup.
Just write a markdown file and it renders with the same
theme as goad-elastic-cyber-range.html automatically.


------------------------------------------------------------
 STEP 1: CREATE A NEW MARKDOWN FILE
------------------------------------------------------------

Create a new file inside the `writeups/` folder, e.g.:

    writeups/my-new-writeup.md

Use a descriptive filename (kebab-case, no spaces).


------------------------------------------------------------
 STEP 2: ADD THE FRONTMATTER (REQUIRED)
------------------------------------------------------------

Start the file with a YAML frontmatter block. This fills
the title, kicker, tags, and lead paragraph at the top of
the page:

    ---
    title: "Your Writeup Title Here"
    kicker: "Category · Subcategory · Topic"
    tags: "Tech1 · Tech2 · Tech3"
    lead: "A short summary paragraph shown under the title."
    toc_extra: "Optional extra TOC link label|https://example.com"
    ---

Field explanations:
  - title      -> The big heading at the top (also sets the browser tab title)
  - kicker     -> The small uppercase green text above the title
  - tags       -> Shown in the meta row (separate with " · ")
  - lead       -> The muted summary paragraph under the meta row
  - toc_extra  -> OPTIONAL. Adds an extra link at the bottom of the
                  Table of Contents (e.g. a "Part 2" external link).
                  Format: "Label|URL"


------------------------------------------------------------
 STEP 3: WRITE THE BODY IN MARKDOWN
------------------------------------------------------------

Use standard markdown. Here's what maps to what:

  ## Section Title          -> Major section (green "##" prefix,
                               auto-numbered in the TOC)
  ### Subsection Title      -> Sub-heading (bullet in the TOC)
  #### Sub-subsection       -> Yellow mono heading

  **bold text**             -> Bold (light cream color)
  *italic text*             -> Italic (muted color)
  `inline code`             -> Inline code (green, bordered)

  - list item               -> Bullet list
  1. numbered item          -> Numbered list

  ---                       -> Horizontal divider (styled)

  > [!NOTE]                 -> Yellow "note" callout box
  > Your note text here

  > [!WARN]                 -> Orange "warning" callout box
  > Your warning text here

  ```bash                  -> Code block (green mono, dark bg)
  your command here
  # comment lines are dimmed automatically
  ```

  | Header 1 | Header 2 |   -> Table (styled as kv-table)
  |----------|----------|
  | cell     | cell     |


------------------------------------------------------------
 STEP 4: ADD IMAGES WITH CAPTIONS
------------------------------------------------------------

To get a styled figure with a caption, put the image on one
line and the caption (italic) on the NEXT line:

    ![Alt text](https://example.com/image.png)
    *This is the caption shown under the image*

The image gets a rounded border and the caption is centered
below it, exactly like the original writeup.


------------------------------------------------------------
 STEP 5: LINK IT FROM index.html
------------------------------------------------------------

Open `index.html` and find the project card you want to
point at the new writeup. Change the href to:

    writeup.html?file=writeups/my-new-writeup.md

Example:

    <a href="writeup.html?file=writeups/my-new-writeup.md" class="card project-card">
      <p class="project-name">My New Writeup</p>
      <p class="project-type">Category · Tags</p>
      <p class="project-desc">Short description shown on the card.</p>
      <span class="project-link">&rarr; read the writeup</span>
    </a>


------------------------------------------------------------
 STEP 6: TEST IT LOCALLY
------------------------------------------------------------

Because the markdown is fetched via JavaScript, you need a
local web server (opening the file directly won't work):

    python3 -m http.server 8080

Then open in your browser:

    http://localhost:8080/writeup.html?file=writeups/my-new-writeup.md


------------------------------------------------------------
 QUICK REFERENCE CHEAT SHEET
------------------------------------------------------------

  Frontmatter keys:  title, kicker, tags, lead, toc_extra
  Figures:           ![alt](url)  followed by  *caption*
  Note callout:      > [!NOTE]
  Warn callout:      > [!WARN]
  Code block:        ```bash ... ```
  Divider:           ---
  TOC:               auto-generated from ## and ### headings
  Read time:         auto-calculated from word count

  URL format:        writeup.html?file=writeups/<filename>.md


------------------------------------------------------------
 EXAMPLE MINIMAL WRITEUP
------------------------------------------------------------

    ---
    title: "My First Markdown Writeup"
    kicker: "Homelab · Security"
    tags: "Proxmox · Elastic"
    lead: "A short intro paragraph."
    ---

    ## Introduction

    Some **bold** text and `inline code`.

    ![Diagram](https://example.com/diagram.png)
    *Network diagram*

    > [!NOTE]
    > A helpful note.

    ```bash
    sudo apt update
    # this comment is dimmed
    ```

    ---

    ## Conclusion

    Done!


That's it. Write the markdown, link it, done.
